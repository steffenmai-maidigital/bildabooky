# BilDaBooky – Überblick: Module & Abläufe

| Modul | Wofür | Wo |
|---|---|---|
| Bibliothek | Bücher der Person und der Klasse, Vorlagen, Klassenbücher | Startseite |
| Editor | Seiten gestalten: Text, Foto, Kamera, Malen, Ton, Sticker, Form | Buch → Bearbeiten |
| Leser | Blättern, Töne hören | Buch → Lesen |
| Mitnehmen | eine HTML-Datei mit allen Bildern und Tönen, Druck/PDF | Buch → ⋯ |
| Klassenbücher und Vorlagen | gemeinsam schreiben; eigene Version aus Vorlage, Abgeben, Zurückgeben | Lehrkraft |
| Benutzer | Klassenlisten anlegen, Passwörter, Anmeldekarten, Schulkonten, Zwei-Faktor-Ausnahmen | Lehrkraft / Admin |
| Klassen und Fächer | Klassen, Fächer, Lehrkräfte je Fach, Anmelde-Sitzungen | Lehrkraft / Admin |
| Konto | Passwort, Zwei-Faktor, Fuchs | alle |
| Einstellungen | Schule, Domain, Farben, Logo, Lizenz, Sommerferien, Fuchs, Anmeldung (Sitzungspflicht, Zwei-Faktor), Schulverzeichnis, Impressum/Datenschutz | Admin |
| Hilfe | Kurzanleitung, System, Lizenz, Handbücher, Änderungshistorie, letzte Fehler, Support | Fußzeile |
| Sicherung | nächtlich, Download für Admins | Scheduler / Einstellungen |
