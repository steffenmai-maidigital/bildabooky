# BilDaBooky – Benutzerhandbuch

Für Kinder, Lehrkräfte und Admins. Für Installation und Betrieb gibt es das
[Administratorhandbuch](ADMIN-GUIDE.md).

## 1. Was ist BilDaBooky?

Eine Buch-Werkstatt für die Grundschule: Kinder schreiben, malen, fotografieren
und sprechen ihre eigenen Bücher. Alles bleibt auf dem Server der Schule.

## 2. Anmelden

- **Kinder** melden sich mit Benutzername und Passwort an (z. B. `mia` /
  `tiger47`), beides steht auf der Anmeldekarte. Ist die Sitzungspflicht
  eingeschaltet, geht das nur, wenn die Lehrkraft die Klasse freigeschaltet
  hat — dann zusätzlich mit dem 6-stelligen Sitzungscode.
- **Lehrkräfte und Admins** melden sich mit ihrem BilDaBooky-Konto oder, wenn
  eingerichtet, mit ihrem Schulkonto an. Ist die Zwei-Faktor-Anmeldung
  eingeschaltet, folgt ein Code aus der Authenticator-App.
- Sprache (🌐) und Hell/Dunkel (◐) stehen oben rechts.

## 3. Die Bibliothek

Nach der Anmeldung siehst du deine Bücher, die Bücher deiner Klasse und
Vorlagen der Lehrkraft.

| Knopf | Was passiert |
|---|---|
| **Neues Buch** | Name und Form (hoch, quadratisch, quer) wählen — fertig |
| **Lesen** | durch das Buch blättern, Töne anhören |
| **Bearbeiten** | Seiten gestalten |
| **⋯** | drucken, als Datei mitnehmen, teilen, kopieren, löschen |

## 4. Der Editor

- **Hinzufügen** (links, am Handy unten): Text, Foto, Kamera, Malen, Ton,
  Sticker, Form, Seitenfarbe.
- **Verschieben**: antippen und ziehen. **Größe**: runder Griff unten rechts.
  **Drehen**: Pfeil oben.
- **Text**: zweimal antippen, dann schreiben; rechts Schrift, Größe, Farbe.
- **Rückgängig** (↶) macht den letzten Schritt rückgängig. Gespeichert wird
  automatisch.
- **Seiten**: unten neue Seite anlegen, Reihenfolge per Ziehen ändern.
- **Rua, der Fuchs** unten rechts (ein Wikinger-Fuchs aus Norwegen) erklärt Knöpfe und gibt Tipps; „Schlafen legen“
  schaltet ihn bis zum nächsten Antippen stumm.

## 5. Teilen, Klassenbücher, Vorlagen

- **Teilen** („mit der Lehrkraft“ oder „mit der Klasse“) über ⋯ beim Buch.
- **Klassenbuch**: die ganze Klasse schreibt gleichzeitig; oben steht, wer
  gerade dabei ist.
- **Vorlage**: die Lehrkraft gibt ein Buch vor; jedes Kind startet seine eigene
  Version und gibt sie mit **Abgeben** ab. Die Lehrkraft kann sie mit einer
  Nachricht zurückgeben.

## 6. Mitnehmen und Drucken

- **Als Datei mitnehmen**: eine HTML-Datei mit allen Bildern und Tönen,
  läuft offline in jedem Browser.
- **Drucken / PDF**: A4 oder quadratisch, über ⋯ beim Buch.

## 7. Für Lehrkräfte

- **Benutzer**: ganze Klassenlisten auf einmal anlegen (eine Zeile je Kind),
  Passwörter zurücksetzen, Anmeldekarten drucken.
- **Klassen**: Bücher der Klasse, Fächer, Anmelde-Sitzung freischalten
  (60/120/180 Minuten oder bis zu 7 Tage) mit Sitzungscode.
- **Änderungsprotokoll** je Buch: wer wann was geändert hat.
- **Zwei-Faktor** unter **Konto** einrichten — empfohlen, für manche Gruppen
  Pflicht.

## 8. Mein Konto

Passwort ändern (eigene Konten), Zwei-Faktor-Anmeldung einrichten oder
ausschalten (wenn erlaubt), Wiederherstellungscodes erzeugen, Fuchs ein- oder
ausblenden. Schulkonten ändern ihr Passwort im Schulverzeichnis.

## 9. Häufige Fragen

| Frage | Antwort |
|---|---|
| Passwort vergessen? | Kinder: Lehrkraft setzt es zurück. Lehrkräfte: Admin setzt es zurück bzw. das Schulverzeichnis. |
| Handy mit der Authenticator-App verloren? | Wiederherstellungscode nutzen oder den Admin bitten, Zwei-Faktor zurückzusetzen. |
| Kamera oder Mikrofon gehen nicht? | BilDaBooky muss über **https://** aufgerufen werden. |
| „Für deine Klasse ist keine Sitzung freigegeben“? | Die Lehrkraft schaltet die Anmeldung unter Klassen → Anmeldung frei. |
